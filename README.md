# Siva Surya L — Portfolio Website

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styles, colours, and animations
- `script.js` — mobile navigation, scroll progress, and reveal animations
- `assets/profile.jpg` — your profile photo

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Internet access is needed for the Google Fonts; the page still works without them.

## Change your profile photo
Replace `assets/profile.jpg` with your preferred portrait. Keep the filename `profile.jpg`.
The uploaded portrait was copied into this folder for the initial version. If you prefer another photo, replace it.

## Publish free using GitHub Pages
1. Sign in to GitHub and create a new repository, for example `siva-surya-portfolio`.
2. Extract this ZIP on your computer.
3. Upload the contents of the `siva_surya_portfolio` folder (the files `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder) to the repository's root. Do not upload only the ZIP.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub will show the published site URL in Settings → Pages.
